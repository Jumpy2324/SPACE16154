SPACE16154 PWA V1
1. Estrai il file ZIP.
2. Carica la cartella su un servizio HTTPS che ospiti file statici (GitHub Pages, Netlify, Vercel, ecc.).
3. Apri l'indirizzo HTTPS dal telefono Android.
4. Dal menu del browser scegli "Aggiungi a schermata Home" / "Installa app".
Nota: la PWA è pronta come struttura demo; per l'installazione PWA completa il sito deve essere servito in HTTPS.
